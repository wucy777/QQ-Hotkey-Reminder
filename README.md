# QQ Hotkey Reminder（QQ 快捷提醒助手）

一个 Windows 小工具：把「待提醒名单」整段粘进来，**按一个全局快捷键，程序自动把下一位待提醒人的 QQ 号输入到 QQ 的搜索框里**，同时把提醒话术复制到剪贴板。你只需要点搜索结果里的人 → 粘贴话术 → 发送，省去每发一条就要手打一次 QQ 号的重复劳动。

- 单个 exe，双击即用，绿色免安装，深色/浅色界面可切换
- 窗口尺寸自动适配屏幕：大屏用 1400×860，小屏（1366×768、1024×600）或高缩放时自动缩小，不会超出屏幕
- 名单不用整理格式，整段粘贴即可，程序拿名单里的名字去文字里检索
- 识别后会列出**没被匹配到的剩余文字**，方便确认有没有漏人（OCR 认错字时很有用）
- 快捷键、话术模板、名字 → QQ 号映射都在界面「配置」页里改
- 人工确认后发送，不会替你自动群发

## 使用步骤

1. 双击 exe（会弹 UAC 请求管理员权限，模拟按键需要）
2. 把待提醒的名单**整段粘到「提醒」页**，点 **识别名单** —— 程序自动把名字换成 QQ 号
   （想让每行单独算一个人，就勾上旁边的 **按行识别**）
3. 点 **开始监听快捷键**
4. 点一下 **QQ 左上角的搜索框**，按快捷键（默认 `F8`）：
   程序自动清空搜索框 → 输入下一位的 QQ 号 → 提醒话术进入剪贴板
5. 点搜索结果里的人 → 聊天框 `Ctrl+V` 粘贴 → 发送 → 回搜索框再按 `F8`，直到全部完成

默认快捷键（可在「配置」页改）：

| 按键 | 作用 |
| --- | --- |
| `F8` | 输入下一位被提醒人 qq |
| `F7` | 重输当前被提醒人 qq |
| `F9` | 跳过当前这位 |
| `F10` | 标记当前这位**发送失败**并置顶（再按一次取消标记） |
| `Ctrl+F12` | 结束并汇总 |

### 发送失败怎么办（F10）

有些好友不允许临时会话，从群里发起聊天会发送失败；或者 QQ 抽风发不出去。这时按一下 `F10`：

- 这个人被标红并排到名单**最前面**，方便你稍后单独换方式联系
- 不影响其他人和 `F8` 的进度，结束后 `Ctrl+F12` 的汇总里也会单独列出「发送失败」的人
- 按错了不要紧，再按一次 `F10` 就能取消标记

名单里认出的人可以随时点右边的 `×` 删掉，删完不影响其他人的处理顺序。

## 识别规则

识别有两种方式，用「待提醒名单」旁边的 **按行识别** 勾选框切换（状态会实时存进配置，下次打开保持）：

**默认：整段检索** —— 拿配置里的名字，去你粘的整段文字里找：

- 名字出现几次就标记几次，找到的人都进右边队列
- 名字被别的字夹在中间也能找到（适合 OCR 出来的一长串文字）
- 识别完如果还有没被标记的文字，会显示在下方让你复核

**按行识别** —— 一行 = 一个人，每行整体拿去配置里找：

- 适合名单本来就是一行一个名字、或 OCR 结果一行一个人
- 没匹配到的行会**按原行号单独列出**（`第 N 行：内容`），方便一行行核对错字
- 行里带序号、括号备注都能认（如 `1. 张三`、`王五（已请假）`）
- 注意：`张三 李四` 写在同一行会匹配不到，拆成两行即可

两种方式都支持：

- 独占一行的 `名字 QQ号` 优先于配置里的映射；名字不在配置里就当作新增
- 名字后面跟 `，QQ号` 或 `, QQ号`（中文逗号也行）时，用你写的 QQ 号
- **只有逗号、分号、冒号、斜杠后的数字才算 QQ 号**；空格后的数字（如学号）一律忽略
- 名字后面紧跟的括号备注（如 `王五（已请假）`）会跟着名字一起识别，不会当成可疑文字
- 名字互为子串时（如同时有「张三」和「张三三」）按长名字优先，不会漏

名字在名单里找不到 QQ 号的，默认改为直接输入姓名搜索（可配置关闭）。

## 配置文件

固定在 `%APPDATA%\QQHotkeyReminder\config.json`（exe 旁边不放任何文件）：

| 字段 | 说明 |
| --- | --- |
| `hotkeys` | 五个快捷键（`next`/`repeat`/`skip`/`failed`/`quit`），写法参考 [keyboard 库](https://github.com/boppreh/keyboard)（如 `f8`、`ctrl+f12`、`alt+q`） |
| `type_delay` | 模拟打字时每个字符的间隔（秒） |
| `clear_before_type` | 输入前是否先「全选+删除」清空搜索框 |
| `search_by_name_fallback` | 没匹配到 QQ 号时是否直接输入姓名搜索 |
| `auto_copy_message` | 是否自动复制提醒话术到剪贴板 |
| `line_mode` | 「按行识别」勾选框的状态（勾一下就会实时写入） |
| `message_template` | 提醒话术模板，`{name}` 会替换成对方名字 |
| `qq_map` | 名字 → QQ 号 的映射表 |

「配置」页里显示的**不是** JSON，而是直白的中文标签和一行一人的名字表：

```text
# 快捷键（写法参考 keyboard 库，如 f8、ctrl+f12、alt+q）
输入下一位被提醒人qq = f8
重输当前被提醒人qq = f7
标记当前这位发送失败并置顶 = f10

模拟打字每个字符的间隔（秒） = 0.03
是否自动复制提醒话术 = true
提醒页是否默认勾选「按行识别」 = false
提醒话术模板（{name} 替换成对方名字） = {name}你好，麻烦尽快完成一下哦

# 名字和 QQ 号，一行一个人（空格或逗号分隔）
张三 10001
李四 10002
```

改完点 **保存配置**，程序自动转回 JSON 写入文件，并校验「编辑框内容 ↔ 配置文件」往返一致后才解锁按钮（执行期间按钮冻结）。没写的项使用默认值。也支持直接写 `hotkeys.next = f8` 这种原始键名。

### 彻底删除本软件数据

不想用了，点配置页右上角的 **彻底删除本软件数据**（红字小按钮）：二次确认后删掉整个 `%APPDATA%\QQHotkeyReminder` 文件夹并退出程序。名单 QQ 映射删掉不可恢复；下次再用本软件会重新生成一样的文件夹。

## 打包成单 exe

```bash
pip install -r requirements.txt
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --icon app.ico --add-data "app.ico;." --add-data "app_icon.png;." --collect-all customtkinter --name QQReminder main.py
# 产物：dist/QQReminder.exe
```

也可以直接运行 `build.bat`。图标由 `tools/make_app_icon.py` 生成。

自检：`QQReminder.exe --selftest`（结果写到同目录 `selftest_result.txt`）。
命令行参数 `--no-elevate` 可跳过自动提权（调试用）。

## 注意事项

- **按快捷键时，鼠标焦点必须停在 QQ 的搜索框里**。程序会先「全选+删除」清空那个输入框再打字，焦点在聊天输入框时按会清空你打的字
- 程序启动时会自动申请管理员权限；取消授权就退出了
- 个别安全软件会拦截全局键盘钩子或模拟按键，误报请自行加白
- 搜索结果请**人工确认**后再发送，避免点错人（程序不会自动发送任何消息）

## 目录结构

```
├── main.py                  # 全部源码（单文件）
├── requirements.txt         # 运行依赖：keyboard、pyperclip、customtkinter、pillow
├── build.bat                # 一键打包脚本
├── app.ico / app_icon.png   # 应用图标
├── tools/make_app_icon.py   # 图标生成脚本
└── %APPDATA%\QQHotkeyReminder\config.json   # 配置（首次运行自动生成）
```
